# 考勤对账工具（机场项目）

自动对账程序：**原始打卡记录 × 手工考勤表（× PDF 支撑单据）**，找出考勤表中所有不一致并输出分级差异报告。

- 阶段一（当前）：原始打卡记录 ↔ 手工考勤表 纯规则对账 + 月度累计重算
- 阶段二（规划）：PDF 扫描单据 OCR → 请假/加班单三方核对
- 阶段三（规划）：每考勤周期末自动运行，沉淀为可复用程序

## 项目结构

```

│   └── report.py            # Excel 差异报告生成
├── tests/                   # 单元测试
└── output/                  # 差异报告输出（不入库）
```

## 环境要求

- Python 3.10+
- 依赖：`openpyxl`（`pip install -r requirements.txt`）

## 使用方法

```bash
pip install -r requirements.txt
python main.py
```

输出：`output/考勤对账差异报告_<周期>.xlsx`，包含 5 个 sheet：
- **差异汇总**：各差异类别数量统计
- **到场核对明细**：有打卡无记录 / 无打卡有√ / 缺卡提醒 / 加班无佐证
- **累计重算明细**：月度累计列 vs 逐日标记求和
- **姓名配对**：原始记录与考勤表姓名归一化（繁简统一）后的配对结果
- **全部差异**：完整明细（可按类别/级别筛选）

差异分级：
- 🔴 **硬错误**：数据自相矛盾，必须修正
- 🟡 **可疑项**：需人工查证（如缺卡、加班无打卡佐证、假单待核对）

## 对账规则（阶段一）

| 规则 | 说明 |
|---|---|
| 姓名配对 | 原始记录与考勤表姓名统一为简体（繁简映射 + 别名表），识别"仅考勤表/仅原始记录"人员 |
| 到场核对 | 有打卡无记录=漏记；无打卡记√=多记/代打卡嫌疑；单次打卡=缺卡提醒 |
| 加班核对 | "加"行有时数但当天无打卡 → 加班无设备佐证 |
| 累计重算 | 培/差/補/年/病/事/其/曠天数（0.5天/标记）、超時工作、休息日上班、週六公眾、夜間工作时数，逐日重算 vs 月度累计列 |
| 餐補核對 | √ 出勤天数 vs 餐補計算（口径待确认，先作可疑项） |
